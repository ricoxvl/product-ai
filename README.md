# Product Intelligence AI

**AI-assisted customer feedback and competitive intelligence for product decisions.**

A portfolio demonstration that turns uploaded feedback and competitor documents into structured themes, sentiment views, competitive comparisons, and product recommendations. It is designed to illustrate the progression from **customer evidence → analysis → prioritization → communication**.

> **Data and privacy:** Use synthetic or explicitly approved, nonconfidential inputs. This repository is a demonstration, not a production company system. Do not upload internal customer information, company files, secrets, or proprietary reports to third-party AI services.

## Quick project overview

| Question | This project demonstrates |
| --- | --- |
| **What problem?** | Product teams need to synthesize scattered customer feedback and competitive research into clearer priorities. |
| **What did I build?** | A Streamlit product-intelligence interface with customer, competitive, combined executive, and natural-language analysis workflows. |
| **How?** | Python, Pandas, Streamlit, Plotly/Matplotlib, document parsing, and Groq-hosted Llama models. |
| **What can a reviewer inspect?** | The dashboard source, analysis and document-processing modules, and a sample feedback dataset. |
| **What is not claimed?** | No verified production deployment, customer outcomes, or measured business impact from this public demo. |

## Features

- **Customer intelligence:** Import feedback CSV/XLSX files, summarize recurring issues, inspect sentiment and themes, and review proposed priorities.
- **Competitive intelligence:** Import supported competitor documents, examine differences, and surface candidate opportunities.
- **Executive analysis:** Combine customer and competitor information into a structured decision-oriented view.
- **AI copilot:** Ask follow-up questions about an analysis and review generated responses.
- **Reporting:** Review visualizations and PDF report-generation code.

Outputs generated by an LLM require human verification; recommendations are not automatically approved roadmap decisions.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ricoxvl/product-ai.git
   cd product-ai
   ```

2. Create an environment and install dependencies:

   ```bash
   python -m venv .venv
   # Windows PowerShell: .venv\Scripts\Activate.ps1
   # macOS/Linux: source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

3. Obtain a Groq API key and **store it locally, never in Git**:

   Create `.streamlit/secrets.toml`:

   ```toml
   GROQ_API_KEY = "your-groq-key-here"
   ```

   The copilot module also reads `GROQ_API_KEY` from the environment (for example, a local ignored `.env`). Set the same value there if using the copilot. Never commit either secrets file.

4. Launch the Streamlit interface:

   ```bash
   streamlit run streamlit_app.py
   ```

5. Explore the customer or competitive workflows with **synthetic sample inputs**. Review any generated conclusions before relying on them.

The separate `app.py` script demonstrates a **local Ollama/Llama** feedback-analysis path. It is not the entry point for the Streamlit dashboard and requires an Ollama installation and its model dependency.

## Product thinking

The goal is not simply to summarize documents. It is to make an evidence-to-decision workflow inspectable:

**Collect feedback → Identify themes → Compare alternatives → Propose priorities → Review with humans.**

Potential next steps include explicit source citations for generated insights, stronger structured evaluation, safer configuration management, test coverage, and deployment documentation.
